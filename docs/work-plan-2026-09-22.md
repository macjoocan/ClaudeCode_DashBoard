## 3. 로컬 두뇌 (`/api/ask`) — 만들었다 (22b1f65)

### 배경

"Claude 가 화면을 만들고 GPT 가 머리를 맡는다" 는 구성을 **API 키 없이** 할 수 있는지 봤다. 된다.

```
codex exec --skip-git-repo-check --output-schema schema.json "..."  < /dev/null
  → 스키마에 맞는 JSON 이 stdout 으로 그대로 나온다
  → 20초 / 23,864 토큰

claude -p "..." --output-format json
  → {"result": "...", "usage": {...}}
  → 12초 / 캐시읽기 16,023 + 출력 191
```

둘 다 **구독 로그인 그대로** 쓴다. API 키도, 추가 과금도 없다.

> MCP 서버를 끄면 토큰이 줄 줄 알았는데 **23,864 → 23,854** 로 거의 그대로였다.
> 비용은 MCP 가 아니라 Codex 자체 기본 맥락이다. 이 방향으로는 더 줄일 게 없다.

### 붙일 모양

```
생성된 화면 (브라우저)
      │  fetch('http://127.0.0.1:7788/api/ask', {provider, prompt, schema})
      ▼
대시보드 (이미 7788 에 떠 있다)
      ├─ codex exec --output-schema     ← 머리 (조사·분석·정리)
      └─ claude -p --output-format json ← 만들기·다듬기
```

화면 쪽 코드는 `fetch` 한 줄이면 되고, 키가 어디에도 안 들어간다.

### 만든 것 (주말)

`ask.js` · `ask-guard.js` · `ask-run.js`. 계획대로 **가드를 먼저** 세웠다.

실제로 눌러 본 결과 (2026-09-28):

```
POST /api/ask  {"provider":"nope", ...}
  -> {"ok":false,"reason":"bad_request","message":"provider 는 claude 또는 codex 여야 한다"}

POST /api/ask  {"provider":"claude","prompt":"1+1 은? 숫자만 한 글자로."}
  -> ok:true, 답 "2", 12초
```

가드가 먼저 막고 정상 요청은 통과한다. GET 은 404 가 맞다 — POST 전용이다.

### 아직 안 한 것

- 맥락 이어가기 (`codex exec resume <세션ID>`)
- 화면 쪽에서 실제로 써 보기. 지금은 엔드포인트만 있고 이걸 부르는 화면이 없다.

### 각오할 것

| | |
|---|---|
| 지연 | 12~20초. 버튼 눌러 분석받는 화면은 OK, 타이핑 반응형은 불가 |
| 비용 | 호출당 16k~24k 토큰. 자동 호출은 반드시 제한 걸 것 |
| 범위 | 내 PC 에서만 돈다. 서버에 올려 서비스하는 건 구독 약관상 안 된다 |

  PTY pid 보다 아래가 되어 세션 상태·ID 연결이 전부 끊긴다. 이 레포가 Codex pid
  역인덱스에서 이미 같은 구덩이를 팠다. CLI 는 부탁만 하고 서버가 PTY 를 갈아끼운다.

## 6. 이 환경에서 반복해서 밟은 지뢰

- **heredoc 이 `\n` 을 깬다.** python heredoc 안에서 `\n` 이 진짜 줄바꿈이 된다.
  `String.fromCharCode(10)` 이나 배열 `.join()` 으로 우회할 것.
- **README.md 는 CRLF 다.** 텍스트 모드로 통째 쓰면 줄끝이 전부 바뀐다. 바이너리 모드로 앵커 치환할 것.
- **측정 대상을 잘못 고르지 말 것.** 대체화면에서는 `viewportY`/`baseY` 가 늘 0이라 스크롤 판정에 못 쓴다.
  "화면이 밀렸나" 는 `baseY` 증가로, "앱으로 샜나" 는 `term.onData` 바이트로 본다.
